# Tep du lieu nop kem

`products.schema-example.json` minh hoa dung schema de thi, khong phai ban export cua du lieu production. Sau khi tao du lieu demo trong Firestore, thay file nay bang JSON export that tu collection `products`. Moi object chi duoc co `name`, `price`, `soluong`, `image`; khong them `id` vao document data.
